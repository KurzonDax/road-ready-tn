# Agents

## Agent skills

### Issue tracker

Issues live in GitHub Issues on KurzonDax/road-ready-tn, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` plus `docs/adr/`, and the existing `docs/DECISIONS.md`. See `docs/agents/domain.md`.
